# 记忆盒子

把 AI 的长期记忆存成你自己手里的一组文件。模型会换、窗口会满、平台会改版，盒子跟着你走。

## 最重要的是思路

这里的文件只是一种写法，每个人的用法都会不一样，文件名、结构、频率都可以改。值得保留的是这几点：

1. **三层记忆**：她是谁（人格）、你们的事（长期记忆）、正在进行（短期记忆）。短期的定期提炼进长期，长期的慢慢沉淀成人格。
2. **定时自检**：让 AI 按固定节奏回顾和整理自己的记忆。多久一次看你们聊得多频繁，不一定要每天。
3. **存提炼，不存原文**；**每条标来源**（你说的 / 她猜的）；**能改也能忘**。
4. **说话方式放原话，别写形容词**，这是换了模型还像她的关键。

- [手动版-零代码](./手动版-零代码/)：5 个文件加 1 段开场指令，适合在聊天 App 里用，约 15 分钟上手。
- [自动版-agent](./自动版-agent/)：完整目录加 5 段提示词，适合能读写文件、能跑定时任务的 agent。
