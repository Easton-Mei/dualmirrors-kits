# 自动版 · 让 agent 自己管记忆

手动版靠你复制粘贴，自动版靠 agent 自己：**每次醒来先读盒子，每晚写日记，每周做整理，换模型前生成唤醒包。**

适合：Claude Code、Codex、能读写本地文件的 agent、带定时任务的 bot 等。

## 结构：三档加载

```
memory-vault/
├── README.md            盒子说明书 + 唤醒流程（新大脑先读这个）
├── index.md             记忆索引：每个文件一句话说明，按需检索
│
├── identity/            【常驻】她是谁
│   ├── core.md          人设核心（≤500 字）
│   ├── voice.md         语言纹理库（原话示例）
│   └── growth.md        她的成长与关系变化
├── user/                【常驻】她眼中的你
│   └── profile.md
├── current/             【常驻】正在进行
│   └── now.md
│
├── memories/            【检索】长期记忆
│   ├── facts.md         稳定事实（带日期和来源）
│   ├── milestones.md    高光时刻（摘要常驻，全文检索）
│   └── episodes/        按月的事件日记
│
├── sessions/            【归档】原始对话，平时不读
├── private/             【归档】敏感内容，永不导出
├── exports/
│   └── boot-pack.md     唤醒包：常驻层合并成一份，贴进任何平台
└── changelog.md         修改记录 + 每次搬家的验证结果
```

- **常驻层**每次都读，总量控制在 3000–4000 字。
- **检索层**先看 `index.md`，用到再翻。
- **归档层**平时不读，只在整理时用。

## 生命周期

| 时机 | 做什么 | 提示词 |
|---|---|---|
| 每次醒来 | 按顺序读常驻层，其余查 index | `prompts/01-唤醒.md` |
| 对话中 | 标记四类事：你说「记住」、她做的承诺、情绪重要时刻、偏好变化 | 写在 README 里 |
| 每晚 | 「睡前写日记」：提炼当天 → episodes / facts / now | `prompts/02-每晚日记.md` |
| 每周 | 「做梦」整理：去重、压缩、清理、更新语气库、重建唤醒包 | `prompts/03-每周整理.md` |
| 换模型 / 平台 | 生成唤醒包 → 新大脑唤醒 → 5 道验证题 | `prompts/04-生成唤醒包.md`、`05-搬家验证.md` |

## 设置步骤

1. 把 `memory-vault/` 复制到 agent 能读写的位置（建议放进一个 git 仓库或定期备份的文件夹，**改坏了能回滚**）。
2. 填好常驻层五个文件（可以从手动版直接搬过来）。
3. 把 `prompts/01-唤醒.md` 放进 agent 的系统提示 / 项目说明（例如 Claude Code 的 `CLAUDE.md`、Codex 的 `AGENTS.md`）。
4. 按 `定时任务怎么配.md` 设好每晚、每周两个定时任务。
5. 第一次跑完日记后，打开 `episodes/` 和 `changelog.md` 检查一遍，确认她记的东西是对的。
