# 定时任务怎么配

不同 agent 的定时方式不一样，但做的事是同一件：**到点了，让 agent 带着对应的提示词跑一次。**

| 任务 | 频率 | 提示词 |
|---|---|---|
| 睡前写日记 | 每天 1 次（建议凌晨，你不聊天的时候） | `prompts/02-每晚日记.md` |
| 做梦整理 | 每周 1 次 | `prompts/03-每周整理.md` |
| 生成唤醒包 | 每周整理后自动跟着跑，或换模型前手动跑 | `prompts/04-生成唤醒包.md` |

## 常见做法

- **自带定时任务的 agent / bot**：新建两个定时任务，内容就是提示词全文，工作目录指向 `memory-vault/`。
- **本地命令行 agent（Claude Code、Codex 等）**：用系统定时器（macOS 的 launchd、Linux 的 cron）在固定时间调用 agent 的非交互模式，把提示词作为输入，并在 `memory-vault/` 目录下运行。
- **没有定时能力**：退回半自动。每次结束对话时说一句「写今天的日记」，每周日说一句「做一次整理」。

## 日记需要原料

日记要从「当天的对话」里提炼。三种原料来源，按方便程度选：
1. agent 自己保存的会话记录，存进 `sessions/`；
2. 平台导出的聊天记录，丢进 `sessions/`；
3. 对话结束时她自己写的当天小结，追加进 `sessions/YYYY-MM-DD.md`。

## 安全提醒

- 定时任务只需要 `memory-vault/` 这一个文件夹的读写权限，别给多余的。
- 每次整理前自动备份（或用 git 提交一次），整理坏了能回滚。
- `private/` 里的内容在任何导出、分享中都要排除。
