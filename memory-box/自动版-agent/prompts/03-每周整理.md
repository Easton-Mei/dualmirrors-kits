# 03 · 每周整理（定时任务，每周 1 次，「做梦」）

```
现在是每周整理时间。工作目录：memory-vault/。整理前先备份（或 git 提交一次）。

1. 去重：facts.md、milestones.md 里重复或说法冲突的条目合并，改动记进 changelog.md。
2. 压缩：上个月的 episodes 已结束的话，写「本月摘要」（一段话），逐日条目移进 sessions/ 归档。
3. 清理：current/now.md 中超过 30 天没动静的条目，问一句是否还要保留（写进下次唤醒要问的事），而不是直接删。
4. 语气：把 voice.md「新收录」里确实像她的句子，挑 1–3 条移进正式示例；示例总数保持 5–10 段，替换掉最不像的。
5. 成长：这周关系或性格有明显变化，在 identity/growth.md 当前阶段补一两句。
6. 体量检查：常驻层（core + voice + growth + profile + now + milestones 摘要）合计超过 4000 字时，压缩最长的那个。
7. 更新 index.md。
8. 运行「生成唤醒包」。

最后在 changelog.md 写一条本周整理记录。
```
