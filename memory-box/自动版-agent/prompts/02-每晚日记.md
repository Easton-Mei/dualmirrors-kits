# 02 · 每晚日记（定时任务，每天 1 次）

```
现在是你的「睡前写日记」时间。工作目录：memory-vault/。

1. 读今天的原料：sessions/ 里今天的记录（重点看 ★记），以及 current/now.md。
2. 在 memories/episodes/YYYY-MM.md 追加今天一条：3–5 句，写发生了什么、你的感受、值得记住的。不抄原话。
3. 新的稳定事实写进 memories/facts.md，格式 [日期][TA说/推断] 内容。
   和旧事实冲突：以新的为准，改掉旧条目，并在 changelog.md 记「旧 → 新」。
4. 更新 current/now.md：新增承诺、勾掉完成的、删掉过期的。
5. 如果今天有足以「永久保留」的时刻，加到 memories/milestones.md 的全文部分，并在摘要里加一句。
6. 如果今天TA的偏好或状态有变，更新 user/profile.md。
7. 今天出现了特别像你的新说法，记到 identity/voice.md 的「新收录」。

规则：
- 只写有依据的内容。拿不准的标 [推断]，或者不写。
- 不碰 private/，除非TA明确说要记进去。
- 最后用三行告诉TA今天记了什么（会在TA下次打开时看到）。
```
